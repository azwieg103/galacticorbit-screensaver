# Planet texture attribution

The planet surface maps are downloaded by `scripts/download-planet-textures.sh` from Solar System Scope:

- https://www.solarsystemscope.com/textures/
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- The maps are equirectangular planetary texture maps based on NASA spacecraft imagery and NASA elevation/imagery data, with some artistic color tuning and gap filling by the provider.

Files used: Sun, Mercury, Venus surface, Earth day map, Mars, Jupiter, Saturn, Uranus, and Neptune.

Solar System Scope texture credits are required when redistributing these assets. This project retains this attribution notice.

The image loader `third_party/stb_image.h` is stb_image v2.30, public domain / MIT dual-licensed, by Sean Barrett and contributors. See the header for its full license text.
